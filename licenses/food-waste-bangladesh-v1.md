# An image dataset for food waste in Bangladesh v1 — CC BY 4.0

Original dataset: Mohammad Manzurul Islam; Saifur Rahman; Fatema Tahsin; Zarif Syndeed Sikder (2025), “An image dataset for food waste in Bangladesh,” Mendeley Data v1, DOI: 10.17632/w68f9w6jmm.1.

License shown on the fixed Mendeley Data v1 page: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Changes in this prepared version: eleven images showing partial people and one image with a QR-code-like mark were excluded; class-name whitespace and one file extension were normalized; the remaining 633 images were split by class into train/validation/test using seed 42. Image pixels were not changed. The Wedding Food waste category remains, with the eleven reviewed images removed.

Branding and product packaging are visible incidentally on some tableware and containers. Their presence does not imply endorsement by the brands or venues. The dataset and its folder labels describe collection contexts; they do not measure the quantity, cost, or prevalence of food waste, or the performance of any named venue. This version is intended for exploratory image classification.
