# Pistachio Image Dataset v1 — attribution and rights review

Source: Murat Koklu (Mendeley Data contributor), *Pistachio Image Dataset*, version 1, DOI `10.17632/h7pf57cgg9.1`, https://data.mendeley.com/datasets/h7pf57cgg9/1. The Mendeley page displays CC BY 4.0 and describes 2,148 images of Kirmizi and Siirt pistachio samples taken with a high-resolution camera.

Required attribution: Murat Koklu, *Pistachio Image Dataset*, Mendeley Data v1, DOI `10.17632/h7pf57cgg9.1`, CC BY 4.0. The source requests citation of these related works:

- Ozkan, I. A., Koklu, M., & Saracoglu, R. (2021). “Classification of Pistachio Species Using Improved K-NN Classifier.” *Progress in Nutrition*, 23(2). DOI: `10.23751/pn.v23i2.9686`.
- Singh, D., Taspinar, Y. S., Kursun, R., Cinar, I., Koklu, M., Ozkan, I. A., & Lee, H.-N. (2022). “Classification and Analysis of Pistachio Species with Pre-Trained Deep Learning Models.” *Electronics*, 11(7), 981. DOI: `10.3390/electronics11070981`.

Changes in this prepared artifact: images were placed in the common `images/<split>/<class>/` layout, with `labels.csv`, `metadata.jsonl`, and train/validation/test splits. Image pixels were not changed. The source ZIP contains feature tables and citation text; those 10 non-image files are excluded. The fixed source ZIP (27,859,492 bytes) was SHA-256 verified before safe extraction. All 2,148 JPEG images were decoded; exact duplicate image contents were not found. Four representative images were visually reviewed and show isolated pistachios on a black background; this sample review is not a full manual image review.

Rights status: the Mendeley dataset page displays CC BY 4.0. The related 2021 journal article has a separate CC BY-NC 4.0 notice. These are recorded separately; the article PDF and figures are not included. Independent confirmation of image rights holders and any third-party rights remains pending. This prepared artifact is not approved for public redistribution and has no Release.

The dataset is for educational classification experiments. It does not establish food quality, safety, freshness, commercial value, or performance on real-world scenes.
