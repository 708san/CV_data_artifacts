# Brazil Road Potholes

2,235 road images and their source pothole masks, reorganized for semantic segmentation. The original 1024×640 RGB images and PNG masks are copied without pixel changes. Train, validation, and test sets are separated by the road-segment key in the filename.

Source: [Mendeley Data v3](https://data.mendeley.com/datasets/t576ydh9v8/3), CC BY 4.0. See the [license record](../../licenses/brazil_road_potholes-v1.md) and [audit report](../../reports/brazil_road_potholes-v0.1.0-audit.json).

Students can prototype a tool that highlights pothole regions in road photos to make a maintenance request easier to document. Images are from Brazilian highways in 2014–2017; they do not represent local roads or current conditions. Model output is not a road-safety judgment.
