# Obstacles Avoidance Assistance v0.1.0

歩道で通行を妨げる可能性がある物体を、画像上の枠で示す物体検出用データです。画像1,250枚、注釈1,627件、4クラスを収録します。

## 生徒が扱える課題

歩道の通りにくさを記録する地図づくりを試作できます。出力はポール・柵・段差・穴などが写る場所を示すだけです。物体が歩行を妨げるか、通行可能かは、歩道の幅や周囲の状況を見て人が確認します。実際の移動支援や安全確保に単独で使わず、当事者・地域の人の確認を前提にします。画像は別地域の歩道で撮影されたものなので、日本の道で使う場合は現地画像で検討し直してください。

## 収録内容

- train: 1,000画像・1,306枠
- valid: 250画像・321枠
- classes: `bump`, `fence`, `hole`, `pole`
- 画像: 640×640 JPEG。元画像の画素データをそのまま収録
- `labels/`: YOLO正規化bbox
- `annotations.jsonl`: 共通形式の画像・枠注釈
- `metadata.jsonl`: splitと注釈数
- test splitは配布元にありません

配布元の説明では、画像は公開Roboflowデータから選び、YOLO形式で手作業ラベルを付けたものです。クラスには柵やポールのように、写っているだけでは歩道の障害物とは限らない物体も含まれます。データが示すのは物体の位置であり、アクセシビリティの判定ではありません。
