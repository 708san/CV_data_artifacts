# 日本語レシートOCR（詳細版）

日本のレシート画像から日付・明細・合計の候補を読み取り、文化祭や部活動の会計入力を補助する仕組みを試すデータです。読取結果は必ず人が原票と照合してください。

- 画像100枚、領域ラベル2,005件、文字転記1,802件。
- 全画像はeval splitです。OCR推論と注釈比較向けで、学習用や網羅的な正解集ではありません。
- labels.csvとmetadata.jsonlに選択領域のラベル、百分率座標、転記を収録。
- 詳細版は基本版1,010枚から選ばれ、追加画像ではありません。

配布元の黒塗りは一部だけで、店舗情報、公開連絡先、QRコード、取引番号が残る場合があります。生徒自身のレシートを共有サービスへアップロードしないでください。個人の特定・プロファイリングは禁止します。CC BY-NC 4.0の非商用条件で利用してください。転記は選択領域だけで、全文OCRの正解集ではありません。
